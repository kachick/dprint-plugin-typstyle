# Contributing

## Overview

This repository is a dprint plugin for Typst. It is a simple wrapper that passes all formatting logic to the `typstyle` crate. It does not have its own formatting logic.

At first, I managed this project with only bash and a small task runner. However, I manage several other dprint plugins and want to use the same setup across them. Because this repository serves as a reference for those plugins, the development setup may feel a bit overly strict for a simple wrapper.

## Pull Requests

Bug reports and pull requests are welcome!

Please note that when I merge pull requests, I often edit the changes and squash commits.
